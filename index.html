Cloudy Resale Sandbox privacy notice

Effective November 15, 2026. This notice describes the isolated Cloudy eBay Sandbox test workspace. It is not a statement that Cloudy is approved by eBay or ready for public production use.

What this workspace processes

Cloudy stores garment records, photographs, measurements, prices and separate marketplace drafts that a seller saves. Connecting eBay exchanges an authorization code for access and refresh tokens. Tokens are encrypted in a server-side database; the encryption key is held separately in server configuration. The workspace uses a password cookie for access. This pilot has one shared workspace owner, not independent user accounts.

What is sent to eBay

Connection requires consent on eBay's Sandbox authorization site. When a seller explicitly approves a prepared listing, Cloudy sends its title, description, price, selected item specifics, category, business-policy identifiers, inventory location and selected photo derivatives to eBay Sandbox. Original saved photograph bytes remain in Cloudy. Reading business policies and listing status supports preparing and reconciling listings. Order retrieval requests Sandbox orders, but Cloudy returns only order and line identifiers, dates, payment/fulfillment statuses, quantities and SKUs. Buyer names, addresses and payment credentials are not retained by this adapter.

Storage, access and retention

Anyone with this private workspace's password can operate its connected Sandbox account. Do not share the password or use real buyer data for testing. OAuth callback query strings and credential payloads are not logged by this entrypoint. The hosting provider and eBay process requests under their own policies. On a free host, local databases may be erased on restart or redeployment; this pilot does not promise durable storage or backups.

Disconnect eBay in the workspace to delete locally stored access and refresh tokens and pending authorization flows. This does not end existing listings or revoke eBay-side consent; also remove application access in your eBay account when desired. Local garment records and listing reconciliation receipts remain until the workspace operator deletes or resets the isolated database. Cloudy does not sell these Sandbox records or use this adapter's private order history as a market-wide sold-data feed.

Questions and deletion

This is an invitation-only operator-managed test workspace. Contact the workspace operator through the same private channel that provided your access to request record deletion or ask questions. A public support address and production retention policy must be established before public launch. Disconnect immediately if you no longer want Cloudy to access the Sandbox account.
